# SRI SQUARE ACCOUNTS

A simple iPhone\-friendly booking, customer billing, financial
accounting, and cash management app for SRI SQUARE\.

## Main Features

### Dashboard

- Clean SRI SQUARE ACCOUNTS dashboard
- Total bookings
- Total booking value
- Cash received
- Balance due
- Quick access to New Booking, Bookings, Customers, Billing,
  Financial, and Cash Balance

### New Booking

Create and save a booking with: \- Booking / Serial Number \- Event Type \-
Customer Name \- Phone Number \- Event Date \- Total Booking Amount \-
Advance Received \- Payment Mode \- Second Advance \- Remarks / Notes \-
Booking terms

### Bookings

- View saved bookings
- Search bookings
- Open booking details
- Resend booking confirmation
- Mark payment as cleared
- Delete bookings when required

### Customers

- Customer name and mobile number directory
- Search by name, mobile number, or booking
- Call customer
- WhatsApp customer
- Copy mobile number

### Customer Billing

Billing is strictly for the customer\.

Customer billing can show: \- Hall / rent amount \- Water \- Power /
electricity \- Other applicable customer charges \- Advance received \-
Balance due \- Customer bill total

Decoration and Lighting are not shown as internal finance calculations
on the customer billing screen\.

Customer bills can be: \- Saved \- Shared as an image \- Sent through
WhatsApp \- Saved / printed as PDF

### Financial

Financial is for internal accounts only\.

Decoration and Lighting are handled as internal finance entries: \-
Decoration @30% \- Lighting @30%

The app can allow the user to enter the commission amount manually or
calculate it automatically from the entered total\.

Financial also includes: \- Financial total \- Expenses \- Financial
balance \- Expense entry \- Payment\-mode information for advances

Final customer payment is not displayed as a separate line in the
internal Financial report\.

### Cash Balance

Cash Balance represents actual physical cash\.

Important rule:

**Cash received increases Cash Balance only when the payment mode is**
**Cash\.**

- Cash → included in physical cash
- UPI → not included in physical cash
- Company Account → not included in physical cash

Cash expenses reduce available cash\.

Customer amounts that are still unpaid are never treated as received
cash\.

### Expense Entry

Internal expenses can be entered with: \- Expense description \- Amount

Expenses are included in the Financial calculation and reduce the
available cash when applicable\.

## Customer Communication

The app supports customer\-facing sharing for: \- Booking Confirmation \-
Customer Bill / Final Bill

Shared customer documents are designed to contain customer\-relevant
details without exposing internal Financial information\.

## Data & Backup

The application is designed for local/offline use\.

Use: \- **Backup Data** to export a JSON backup \- **Restore Data** to
import a previously created SRI SQUARE ACCOUNTS JSON backup

### Important

Always create a backup before making major app updates, clearing
browser/site data, or replacing the application files\.

## Installation on iPhone

1. Open the GitHub Pages website in Safari\.
2. Use Safari’s **Share** menu\.
3. Select **Add to Home Screen**\.
4. Open SRI SQUARE ACCOUNTS from the iPhone Home Screen\.

## GitHub Pages

The application is intended to run as an iPhone\-friendly Progressive Web
App &#40;PWA&#41; on GitHub Pages\.

Required app files include: \- `index.html` \- `manifest.json` \- `sw.js` \-
App icons
